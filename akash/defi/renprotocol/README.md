# renprotocol

From [Ren Protocol](https://github.com/renproject/bridge)
The easy and permission-less way to bring cross-chain assets to Ethereum.

## Use Cases

- Decentralized finance
- Blockchain node operation
- Network validation

## Getting Started

1. Deploy the template and wait for the service to reach "Running" status
2. Open the web interface at `http://{SERVICE_URI}:80/`
3. Follow any on-screen setup instructions

## Accessing the Service

Open `http://{SERVICE_URI}/` in your browser.

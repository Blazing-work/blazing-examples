# steemcn

SteemCN is a social blogging platform where you can monetize your contents

## Use Cases

- Content publishing
- Blog hosting
- Content management

## Getting Started

1. Deploy the template and wait for the service to reach "Running" status
2. Open the web interface at `http://{SERVICE_URI}:3000/`
3. Follow any on-screen setup instructions

## Accessing the Service

Open `http://{SERVICE_URI}:3000/` in your browser.

## Deployment Specs

| Resource | Value |
|----------|-------|
| Image | `ericet/steem-buzz:latest` |
| CPU | 1.0 |
| Memory | 1024Mi |
| Storage | 1024Mi |
| Exposed Ports | 3000 |

# adminer

Adminer is a full-featured database management tool written in PHP, supporting MySQL, PostgreSQL, SQLite, MS SQL, Oracle, and more.

## Use Cases

- Database administration via web browser
- Quick SQL query execution
- Data import/export
- Schema management

## Getting Started

1. Navigate to the web UI
2. Enter your database server address and credentials
3. Browse tables, run queries, and manage your data

## Accessing the Service

Open the web interface at `http://{SERVICE_URI}:8080/`

## Deployment Specs

| Resource | Value |
|----------|-------|
| Image | `adminer` |
| CPU | 0.1 |
| Memory | 512Mi |
| Storage | 512Mi |
| Exposed Ports | 8080 |

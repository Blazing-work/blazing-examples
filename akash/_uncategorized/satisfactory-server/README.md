## Getting Started

1. Deploy the template and wait for the service to reach "Running" status
2. Connect to the service on port `15000`
3. Refer to the official documentation for usage instructions

## Accessing the Service

Connect to the service on port `15000`. Replace `{SERVICE_URI}` with your deployment's assigned URI.

| Resource | Value |
